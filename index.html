Comandos básicos em forma de história:
Hoje utilizei o comando ´touch' para criar cada arquivo desse repositório, quando utilizamos direto do terminal, o comando ´touch' cria um arquivo vazio com o nome especificado. Por exemplo, ao executar ´touch main.html', um novo arquivo chamado 'main.html' é criado no diretório atual. utilizei touch main.html que é tudo isso que vocês estão vendo agora, e depois utilizei touch style.css para criar o arquivo de estilo que está sendo referenciado no main.html. e o script.js quando for necessário, mas por enquanto está vazio.

Terminal é uma interface de texto que onde podemos interagir com o sistema operacional, executar comandos e tudo mais, é importante lembrar que os repositórios de pacotes são diferentes entre as distribuições linux, exemplo no ubunto utiliza-se o apt, no arch utiliza-se o pacman. hoje aprendi a diferença entre shell, terminal e linha de comando, o shell é o interpretador de comandos, o terminal é a interface que permite interagir com o shell, e a linha de comando é onde digitamos os comandos, até ontem chamava tudo de terminal, mas agora sei que é mais complexo do que isso, e é importante saber a diferença. revisei alguns comandos básicos como ls, cd, pwd, mkdir, rm, mv, cp, cat, echo, clear, history e outros. Aprendi a navegar entre diretórios, criar e remover arquivos e diretórios, copiar e mover arquivos, visualizar o conteúdo de arquivos e limpar a tela do terminal. - essa parte honestamente você pode conferir no material anexado.

revisei também que `curl` é a ferramenta que permite fazermos requisições HTTP diretamente do terminal, e `wget` é uma ferramenta para baixar arquivos da web. Ambos são úteis para interagir com recursos online sem precisar de um navegador - já faço isso no meu dia a dia, mas hoje peguei o conceito de fato. vi a diferença entre cat e less, o `cat` exibe o conteúdo de um arquivo inteiro de uma vez, enquanto o `less` permite visualizar o conteúdo de forma paginada, facilitando a leitura de arquivos grandes. nesse atual momento estou aprendendo a diferença entre AWK, TR e SED. são 08:43. se houver atualizações sobre isso, irei atualizar o blog, mas por enquanto é isso, e é isso que estou aprendendo hoje, e é isso que estou compartilhando com vocês. referências que utilizei esse para esse dia: Referência 1 Referência 2 e BEM HONESTO QUE AULA BOA ESSE SEGUNDO LINK - MIT É QUALIDADE PURA!

Git Hub - REVOLUCIONÁRIO
Gh - para qualquer pessoa do meio não Tech, pode achar que GH é apenas o hormônio de crescimento, mas no meio Tech, GH é a sigla para Github.

O importante antes de falarmos de Github é falar sobre controle de versão, termo esse extremamente importante é onde fica registrado as mudanças dos arquivos que traz apoio em caso de necessidade de backup ou recuperar uma versão anterior a um desastre nos arquivos - como gosto de analogias é tipo um pedreiro tivesse o poder construir uma parede e essa parede por algum motivo pegar umidade, ele poderia voltar na versão onde não tinha a umidade e realizar a correção necessária. A little bit of story, do português um pouco de história - Linus Torvalds é não apenas criador do Linux mas também pai do sistema Git mais precisamente por volta de 2005 após a ferramenta BitKeeper perder suas forças, caramba já fazem 21 anos, eu particularmente estava com 1 ano de vida, em vez de estar programando tava preocupado em aprender a andar enquanto isso o cara tava lançando o maior sistema de versionamento do mundo moderno, o cara certamente é bom. Vale ressaltar que o Git evoluiu muito nesses 21 anos. O bacana é que o git não armazena os dados como outros sistemas de VCS - o git realiza esse versionamento através de Snapshots de um sistema de arquivos em miniatura - a cada commit ele tira uma foto de como os arquivos se parecem naquele momento e se torna a referência atual. Além do mais, quase toda operação é local o que faz com que cause a sensação de velocidade absurda, mas é por consultar o histórico do projeto ali no disco local em vez de consultar um servidor remoto fazer ou extrair uma versão mais antiga.
